LESSON 620.2.6 · BOARD CONFIGURATION

配置 swimlanes、卡片、工作日與 issue detail

用 board 設定降低辨識成本；同時知道哪些只改畫面、哪些會影響報表。

考綱目標：Configure board swimlanes, card colors, card layout, working days, and issue detail view

每天站會需要什麼資訊？

站會中大家反覆問「是哪個 project？誰負責？快到期嗎？」可以透過 swimlanes 與卡片欄位先回答。若每個人都打開整張 issue 才能辨識工作，板上可能少了重要資訊；但把所有欄位堆上去，也會讓關鍵訊息消失。

Swimlanes 用橫向分組回答不同問題

方式適用問題注意
Queries哪些工作需優先處理？用 JQL 分 expedite／一般。依查詢次序分類；Everything Else 接住未匹配工作。先把較具體規則放前面。
Stories一筆 parent 下的 subtasks 如何分工？每筆有 subtasks 的 parent 一條泳道；沒有 subtasks 的工作另列。
Assignees每個人目前手上有哪些工作？可安排未指派工作在上或下；不是授予工作權限。
Epics各大功能下的工作如何分布？Epic 不在 board filter 範圍內會影響顯示，缺卡時要一起查 parent。
Projects／Spaces跨 project 工作各有哪些？保留來源歸屬，適合共同板。
No swimlanes只需單純欄位流動。減少分組不會刪工作。

在 Board settings → Layout → Swimlanes 選方法；Query 模式可新增與排序。Swimlane 中的 ORDER BY 不用來改卡片排序，卡片仍依板的 rank 呈現。某些新版畫面另有個人的 Group by／View settings；操作時先辨認你是在改共用設定還是自己的視圖。

分組未顯示，不等於設定被刪除

Queries swimlane 是依條件把本來就在板範圍內的工作分組；條件重疊時應將特定、優先的規則排在較前面，避免一般規則先接走工作。不要把同一張卡片想成每個匹配泳道都複製一張。Card colors 同樣以第一條匹配 query 決定顏色，但兩種規則各自配置，調色順序不會調泳道順序。

某條泳道看不到時，先查當前範圍是否還有符合工作、quick filters 是否排掉它，以及泳道是否收合；空泳道的呈現依當前視圖確認，不能只憑沒有橫列就重建設定。Epic swimlane 還要查 parent 是否在 board filter 範圍內。目前 Configure swimlanes 主文並未完整規定所有新版空泳道顯示行為，實作時以原設定存在與否及匹配資料共同驗證。

Card colors 與 Card layout 分工

Card colors：可依 issue type、priority、assignee 或 JQL 指定顏色，設定以 board 為單位。Query 顏色採第一個匹配規則；例如「urgent 紅色」置頂、「Bug 黃色」第二，兼具 urgent 與 Bug 的卡片會紅色。顏色只是訊號，不會把 Priority 改成 Highest，也不會觸發 escalation。

Card layout：可增加最多三個額外欄位。Scrum 的 backlog 與 Active sprints 可不同：backlog 顯示 Fix version、Component、Due date，執行板則依團隊需要挑最常用的資訊。新增卡片欄位不等於新增 custom field，也不等於改整張 issue layout。

Days in column：顯示工作停留時間以利找瓶頸。若工作離開又回到同一欄，指標會累計它在該欄的時間，不只計最後一次回來。不要把點點數當成個人工時或工作量估算。

Card cover：新版可能支援封面圖／顏色；它和依 JQL 套用的 card color 不同。資訊仍應有文字標記，不要只靠顏色辨識緊急工作。

Team-managed 也能調整卡片顯示，但能力要分清楚

目前官方的 View settings 同時涵蓋 company-managed 與 team-managed，且設定以使用者為單位，不會改掉其他人的視圖。Team-managed 可在 Board 顯示或隱藏 work type、key、epic、linked work items、priority、assignee、card cover，以及 Due date、Labels；Backlog 也能切換其提供的欄位，例如 Due date。

因此「team-managed 完全不能調整 board／backlog 卡片欄位」已不準確。但官方仍將「Card layout 增加最多三個額外欄位」明確標為 company-managed 功能；不能把內建欄位的顯示開關解讀成任意新增 custom fields。使用題目中的精確需求判斷：是顯示／隱藏提供的欄位，還是挑三個額外欄位？官方：Customize your view of the board and backlog。

沒有 Status 著色選單，就不能依狀態上色嗎？

可以使用 Queries，例如 status = "In Review"。直接方法是 issue type、priority、assignee 與 Queries；「依某欄位寫 JQL」不代表該欄位也有獨立選單。Saved filter 同樣不是另一種直接方法，可在 Queries 用 filter = 12345 引用有權存取的篩選器。比較選項時，先分清楚介面方法名稱與查詢能表達的條件。

Working days 會影響報表的時間背景

Board settings → Working days 可設定固定上班日、特定 non-working dates 與 board timezone。團隊在台灣、週一至週五工作，可選合適 Asia／Taipei 時區並加入休假日；這是在定義報表用的日曆，不是禁止週末 transition，也不會替你排出每位成員的休假。

官方列出的相關項目包含 Burndown、Sprint Report、Epic Report、Version Report、Control Chart，以及 Sprint Health／Burndown gadgets。若報表的理想線或經過時間與預期不符，先查日曆與時區；不要直接推論 issue history 壞掉。各報表仍有自己的計算規則，見 620.5.3。

反例：Burndown 今天變陡，是否只有 Working days 設錯一種原因？

不是。還可能是工作完成、remaining estimate 調整、範圍加入／移除、報表選了不同 sprint／statistic、board filter 或 mapping 改變。Working days 是時間背景的一項配置；先讀事件與資料，再查日曆，避免看到任何曲線差異都歸咎假日。

Issue detail view 不只是 Card layout 放大版

點卡片會開啟 issue，顯示更多欄位與操作。舊教材稱 Issue Detail View；目前文件導向 Work item view／field layout 與 Screens。Project admin 可在允許範圍內配置 layout；欄位是否真的出現，還受 field context、issue type、screen、field configuration 與權限影響。

若 Component 欄看不到可選值，應查 project 是否已有 component；若 Fix versions 沒有選項，先查 versions。若欄位被 field configuration 隱藏，只調 board card layout 不能修復。深入配置見 620.3.6。

需求配對：想顯示到期日、區分緊急工作、忽略休假日，分別用什麼？

到期日放 Card layout；緊急工作用文字 label 加 Card colors／Queries swimlane；休假日用 Working days。三者各有用途，不要讓一條 JQL 同時承擔所有介面設定。

Demo lab：設計可讀的站會板

  1. 使用獨立 ACP620 Cross Lab，記下原 swimlanes、colors、layout、working days。
  2. Swimlanes 選 Projects／Spaces；預期 WEBLAB、APILAB 工作分開。再切 Queries，新建 labels = urgent 的「需注意」泳道；替一筆測試工作加入 urgent，確認其他工作落在 Everything Else。
  3. Card colors 選 Queries，urgent 設紅色放第一，issuetype = Bug 設另一色放第二。用一筆同時符合兩者的測試 Bug 驗證第一規則優先。
  4. Card layout 加 Due date、Component、Fix versions，最多三個；先為測試工作填入對應資料。預期卡片顯示摘要資訊，並非完整 issue 畫面。
  5. Working days 設週一至週五、Asia／Taipei，加入一個測試 non-working date。打開相關報表查時間背景；若沒有足夠 sprint／history 資料，不宣稱已驗證曲線效果。
  6. 打開卡片，比較 issue detail 與 card layout；練習後回復原設定與測試 label。

驗收：能為每個需求選正確配置，且區分視覺效果、資料修改與報表日曆。

五題 board 顯示設定

以下皆為原創單選情境題，非官方考古題。先選答案，再展開解析；每題只有一個最佳答案。

1．跨 project 站會想按來源分區，哪個最直接？

  1. Working days
  2. Projects／Spaces swimlanes
  3. Rank custom field 複製
  4. 改 issue security
查看答案與四個選項解析

答案：B

A：日曆不分工作來源。

B：一個 project 一條泳道符合需求。

C：不應複製 Rank，也不能取代分組。

D：Security 控制可讀權，不是分類。

English version

A cross-project stand-up needs grouping by source project. What fits best?

  1. Working days
  2. Projects or Spaces swimlanes
  3. Duplicate the Rank field
  4. Change issue security
Answer and explanations

Answer: B

A: A calendar does not group by source.

B: One lane per project directly meets the need.

C: Rank should not be duplicated and is not a grouping mechanism.

D: Security controls access rather than presentation categories.

2．卡片符合兩個 Query colors，使用哪個？

  1. 最後一個
  2. 隨機
  3. 第一個匹配規則
  4. 一定 priority 色
查看答案與四個選項解析

答案：C

A：不是最後匹配。

B：規則順序有意義。

C：應將較具體、較重要規則放前。

D：已選 Queries 方法時依 query 規則。

English version

A card matches two query-based color rules. Which applies?

  1. The last rule
  2. A random rule
  3. The first matching rule
  4. Always the priority color
Answer and explanations

Answer: C

A: It is not the last match.

B: The order is meaningful.

C: Put more specific or important rules earlier.

D: When Queries is selected, query rules determine the color.

3．Company-managed card layout 最多加幾個額外欄位？

  1. 三個
  2. 一個
  3. 無限
  4. 等於所有 custom fields
查看答案與四個選項解析

答案：A

A：官方設定最多三個。

B：不只一個。

C：卡片資訊刻意有限。

D：不會自動列出全部 custom fields。

English version

How many additional fields can company-managed card layout display?

  1. Three
  2. One
  3. Unlimited
  4. All custom fields
Answer and explanations

Answer: A

A: The documented limit is three additional fields.

B: It permits more than one.

C: Card information is deliberately limited.

D: It does not automatically list all custom fields.

4．設定週末 non-working，代表？

  1. 週末不能登入
  2. 週末禁止移動 issue
  3. 自動刪週末 worklogs
  4. 影響相關報表／gadgets 的日曆
查看答案與四個選項解析

答案：D

A：不是登入控制。

B：不是 transition 限制。

C：不會刪資料。

D：這是 board 工作日設定的用途。

English version

Marking weekends as non-working means what?

  1. Weekend login is blocked
  2. Weekend transitions are forbidden
  3. Weekend worklogs are deleted
  4. Relevant reports and gadgets use the configured calendar
Answer and explanations

Answer: D

A: It is not a login control.

B: It does not restrict workflow transitions.

C: It does not delete data.

D: This is the purpose of the board’s working-days configuration.

5．Card layout 加欄位仍無值，應如何？

  1. 一直增加欄位
  2. 查 issue 實際值與欄位適用／顯示配置
  3. 改 project 名稱
  4. 認定資料遭刪除
查看答案與四個選項解析

答案：B

A：顯示欄位不會產生資料。

B：從資料與 configuration 查較準確。

C：名稱不補欄位值。

D：空白不證明被刪除。

English version

A field added to card layout has no value. What should you do?

  1. Keep adding fields
  2. Check the issue’s value and field applicability or visibility
  3. Rename the project
  4. Assume the data was deleted
Answer and explanations

Answer: B

A: Showing a field does not create its value.

B: Inspect data and configuration first.

C: A name change does not supply values.

D: Blank display does not prove deletion.
