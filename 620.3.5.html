把「為什麼派給他」拆成可驗證的規則

一張新 Bug 同時屬於 Payments 與 Notifications，建立時選 Automatic，最後卻不是 project lead 負責。這不一定是錯誤：components 的預設可覆蓋 project default。要判讀結果，先記下每個 component 的設定、目標人的 Assignable User，以及是否有 automation 在建立後改寫。

Project 與 component 的四種預設

Component default會派給誰注意
Component lead該 component 的 lead只填 lead 而未選這個 default，不代表必定派他
Project lead／Space owner本 project 的 lead／owner與 project default 可能不同
Project default回到 project 的 Default assignee若 project default 是 Unassigned，就可能沒有人
Unassigned保持未指派站台需允許未指派

Project settings → Details 的 Default assignee 通常只提供 Project lead／Space owner 或 Unassigned。若想要固定指定某個人，傳統做法是改 project lead，或使用 component／automation；不要把「Default assignee」誤認為任意成員選單。這項改動不會自動把所有歷史工作重新指派。

多 component：先優先級，再看名稱

官方 Cloud KB 提供的建立工作優先級是 Component lead → Project lead → Unassigned → Project default。當多個 components 都以 component lead 為預設，取 component 名稱字母順序最前者的 lead，不是 lead 的名字，也不是你點選 component 的先後順序。前提是候選人有可被指派資格。

Components（名稱：預設）預測原因

Payments：Component lead=Amy；Notifications：Component lead=ZoeZoe同級比較 component 名稱，Notifications 在 Payments 前

文件差異：Configure Jira components 用「不同預設負責人取 component 字母序最前」概括；Cloud 指派 KB 明列上述優先級。混合 default 類型時本課依 KB 的更詳細規則教學，並要求在 demo 驗證；不要把簡化句套到所有混合情境。新版介面另可能允許直接指定某人，超出 KB 列示的四種角色組合，應以實測判定。

Automation 可以明確派工，也可能覆寫

需求若是「Priority=Highest 就派值班人，否則在三位成員間輪流」，靜態 project default 不夠。Automation 的 Assign issue action 可指定某人、事件觸發者、其他欄位中的人、smart value、角色／群組、依名單 round-robin／random／balanced workload 等。Balanced workload 依設定 JQL 的工作數衡量，不是自動理解每張工作難度。

先決定規則是否應保留人工指派。如果只想補未指派的工作，加入 Assignee is empty 條件；若需求要求強制派值班人，才明確說明會改掉人工值。Rule actor 必須有 Assign Issues，目標人必須有 Assignable User。自動化詳細設計與 audit log 見 620.4.2、620.4.3。

先判斷：建好後先出現 Amy，數秒後變 Ben，要查哪裡？

先看 issue History 的修改者與時間，再查同時段 automation audit log。若建立時已是 Amy，component 選擇可能正確；後續規則改成 Ben 是另一個事件。不要一直改 component 名稱來修正 automation。

Automation actions 文件把 Automatic 描述為 project default；issue 表單的 Automatic 另有 component 邏輯。比較這兩種入口時先看實際 action 設定與 audit log；考題未說 automation 時，不自行加上不存在的規則。

指派異常的排查清單

  1. 開 issue History，確認建立時 assignee 與後續變更；先分清「初始指派」或「後續覆寫」。
  2. 確認建立者是否選明確使用者，或真的使用 Automatic；Unassigned 是空值結果，不是 Automatic 的同義詞。
  3. 列出每個 component 的 Name、Lead、Default assignee，先按類型優先級，再處理同級字母序。
  4. 檢查候選人帳號狀態、project 存取與 Assignable User。無資格的人不能只因是 lead 就強制成為 assignee。
  5. 查 project default 與未指派是否允許；若 component 不提供有效目標，記錄 fallback／錯誤結果，勿假設所有失效情境都有同一 fallback。
  6. 查 automation scope、conditions、actor 權限、audit log 與 workflow post functions；確認沒有第二條規則反覆改寫。

Demo lab：用結果表驗證四種組合

  1. 準備專用 company-managed project，使用 Jira components，記錄 project lead 與 default。準備 Amy、Ben 等兩個可被指派的測試帳號，確認 Assignable User。
  2. 建立 Alpha（Project default）、Payments（Component lead=Amy）、Notifications（Component lead=Ben）。暫停「僅此測試 project」的測試派工規則，勿停正式全站規則；若有共用規則，改用不匹配的測試條件。
  3. 建第一張：無 component、Automatic，預期 project default。第二張：Payments、Automatic，預期 Amy。
  4. 第三張：Payments + Notifications、Automatic，預期 Ben；交換選取順序再建一張，結果仍依 component 名稱。
  5. 第四張：Alpha + Payments、Automatic，依 Cloud KB 預期 Amy。若站台不同，保留設定、版本與 History，視為文件／rollout 差異，不硬說已符合。
  6. 第五張：明確選 Ben + Payments，預期 Ben。若後續改掉，查看 History／audit log。完成後還原本次測試設定並移除測試資料。

題目 1．Payments lead=Amy，default=Project default，project default=Unassigned；Automatic 結果？

  1. 一定 Amy
  2. Unassigned（允許未指派時）
  3. 一定建立者
  4. 兩個人共同負責
查看答案與逐項解析

答案 B。A 只看到 lead 未看 default；B 沿 Project default 回到空值；C 無此預設規則；D assignee 是單值。

English version

Payments has lead Amy but default Project default; the project default is Unassigned. What does Automatic produce?

  1. Always Amy
  2. Unassigned, if allowed
  3. Always the creator
  4. Two assignees

B. A ignores the default setting. B follows the fallback. C is not the rule. D is impossible for a single Assignee field.

  4. Reporter

Zebra uses Component lead; Alpha uses Project default. Which wins under the Cloud KB rule?

Two components both use their leads as defaults. What breaks the tie?

An issue is explicitly assigned to Amy, then changes to Ben seconds later. What should you inspect?

A. A identifies later changes and actors. B is excessive. C does not diagnose an overwrite. D is inappropriate.

What condition helps avoid overwriting a manual assignment?
